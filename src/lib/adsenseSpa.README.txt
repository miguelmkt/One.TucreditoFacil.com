INTEGRAÇÃO SPA AdSense

1. Importe e chame em cada página SPA que exibe anúncios:
   import { reloadAdsSafely, attachAdSenseSpaListeners } from '../lib/adsenseSpa';
   useEffect(() => {
     attachAdSenseSpaListeners();
     reloadAdsSafely();
   }, []);

2. Remova qualquer uso de location.reload, window.location.href, etc.

3. Garanta que os blocos <ins class="adsbygoogle"> estejam presentes no DOM após cada navegação.

4. O sistema detecta pushState, replaceState, popstate e recarrega anúncios sem duplicar.

5. O collapse de espaço vazio é automático. Ajuste minAdHeight/skeleton se quiser.

6. Compatível com React, Vite, mobile Safari, lazy loading, Google Analytics.
